# ADR 0007: 資料づくり(3 巡目)で挙がったツール側の改善要望

- 状態: 提案(未実装。着手順は未決)
- 日付: 2026-10-12
- 基点: `main`(ADR 0006 の `--html` まで)
- 関連: ADR 0004, ADR 0005

## 背景

講演資料を作る側から、次の 11 件の要望が届いた。スライド担当(ai-impact-for-ses)から詳細を受け取った(下の「deck 側の詳細」)。講演は 2026-10-23。deck は `hisco-2026-10/diagrams/` の `.ts` を Slidev(16:9、論理サイズ 980x552)で表示し、出力は `public/svg/`。実装が間に合わなくても、資料は CSS で成立させる。下の「方向の案」は実装者の仮の案で、確定ではない。

| 優先度 | # | 要望 | 方向の案 |
|---|---|---|---|
| 高 | 1 | ダークテーマと透明背景 | テーマのトークン一式を暗色用に切り替える設定と、背景を塗らない出力。検査(コントラスト)も暗色で行う |
| 高 | 2 | 段階で消える・置き換わる表示(号令の棒が許可の棒に変わる、など) | 既存の `reveal` に「この段階で消える」「別の部品に置き換わる」を足す |
| 高 | 3 | 人数の並び(100 人中 76 人の絵) | quantity 系の部品(ADR 0002)に、人のアイコンの格子(N 個中 k 個を強調) |
| 高 | 4 | 画像の埋め込み部品(台所の絵などを、文字や強調と重ねる) | 画像を部品として置き、上に文字・spotlight を重ねられるようにする。検査は画像の上の文字のコントラストをどう見るかが論点 |
| 中 | 5 | 時間軸と期限の部品(塩漬けシステムの期限) | 横軸が時間の部品。期限の線と、そこまでの残りを出す |
| 中 | 6 | レーン上の点の分布(ついてこれない人) | swimlane / plane のレーン上に、点の群れを置く |
| 中 | 7 | スライド用キャンバス(16:9、最小文字 24px) | 16:9 の寸法と、最小文字サイズを 24px とする検査の組み合わせ(既存の slide-budget との関係を要確認) |
| 中 | 8 | 出典行の固定位置 | 図の下端など決まった位置に出典を置く部品 |
| 低 | 9 | 既定のプレビューでカラー絵文字を描く | 既定エンジンでも絵文字を描く(ADR 0005 #4 は chromium 側の修正だった) |
| 低 | 10 | spotlight と muted の併用警告の抑止 | 意図した併用を明示すれば警告を出さない |
| 低 | 11 | 文字を 4px の格子に丸める案の再検討 | ADR 0005 #8 で「ほぼ全図の SVG が最大 2px 動く」として見送った案。差分を許容できる条件を決めて再判断 |

## deck 側の詳細

優先順位は deck 側の仮の見立て(#1 #2 #3 #4 > #5〜#8 > #9〜#11)。最終判断はユーザー。

| # | 見つけた図 | 欲しい形 |
|---|---|---|
| 1 | 載せたい先: `d46-same-power.ts`, `d44-hurdle-gap.ts`(今は Slidev の CSS だけ) | 背景 #0b1220、文字は白、主役 #60a5fa、打ち消し #94a3b8、扉は背景 #1e3a8a。用途は「濃い背景のスライドに図だけを透明で重ねる」。細かい色は未定 |
| 2 | `d46-same-power.ts`(号令の棒→許可の棒)、`d44-hurdle-gap.ts`(赤い高い棒→青い低い棒)。今は reveal で足すだけ | 同じ位置・同じ寸法で別の部品に入れ替わる。動きは不要。「段階 N で消える」だけでも足りる |
| 3 | `d14-gap-76-31.ts`(76% と 31%、補助 82%/35%) | 人アイコン 100 個を 10x10 に並べ、76 個と 31 個を色分け。寸法は未定 |
| 4 | 実装先の図は未作成(台所の 1 枚絵とランナーの絵を gpt-image-2 で作る。`d47-meal-kit.ts` の前に置く案) | 画像は背景として全面か大きく置き、文字・矢印・強調を上に重ねる。文字は画像に入れない |
| 5 | `d10-chain.ts`(塩漬けシステムの連鎖)。RDS MySQL 5.7 の Extended Support 終了は 2027-02-28 | 1 本の横軸、期限の縦線、迫る区間の塗り。寸法は未定 |
| 6 | 新規。`d48-worksheet-before-after.ts` を置き換える案 | 横並びの点。前は後ろに数個離れ、後は集団に入る。2 場面の比較 |
| 7 | (特定の図なし) | 16:9 なら何でもよい(Slidev 側が縮尺)。1920x1080 基準で最小文字 24px は案。会場の後ろ(約 20m)から読めること |
| 8 | `d14-gap-76-31.ts`, `d27-three-theories.ts` ほか数十枚で caption 位置がばらばら | 図の下端、左寄せ、小さい灰色 |
| 9 | `d47-meal-kit.ts`, `d21-low-hurdle-steps.ts`, `d38-next-week.ts`(ラベルに絵文字) | 既定のプレビューで絵文字が描かれない |
| 10 | `d15-three-layers.ts`(spotlight と muted の箱を意図して併用) | 意図した併用では警告を出さない |
| 11 | `d41-plans.ts` の banner(padY を 6 に直して回避済み) | 優先度は低い |

## 論点(着手前に決める)

- #1 と #4 と #7 は、検査(コントラスト・文字サイズ・余白)の前提を変える。先に検査の側の方針を決める。
- #2 は既存の `reveal` / `spotlight` の意味を広げるので、ADR 0003 までの語彙との整合を見る。
- #3 / #5 / #6 は新しい部品。ADR 0002 の quantity 部品に寄せるか、別部品にするかを決める。
- #11 は #8(出典行)や #9 とは独立だが、既存の全 SVG の差分を伴う。
