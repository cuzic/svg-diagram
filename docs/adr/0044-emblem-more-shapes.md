# ADR 0044: `emblem()` の図形を増やす — 台形・平行四辺形・五角形・端子・角丸四角・書類・円柱

- 状態: 実装済み(PR #335)。実フォントでの余白の測定済み。Opus レビュー 1 巡目(中 2・低 3)を反映中
- 日付: 2026-10-22
- 基点: `main`(PR #333 まで)
- 関連: ADR 0043(`emblem()`)、ADR 0041(`flowchart()`。「入出力・書類・データベースなどの記号は、後で `kind` を足せる形に」)
- 範囲外: 星形・パスで渡す自由な図形(要望で外した)、`flowchart()` の `kind` への追加(要望で `emblem` だけにした)、項目単位の spotlight

## 背景

ADR 0043 で、円・四角・三角・ひし形・六角形の中に文字を入れる `emblem()` を足した。利用者から「台形や、フローチャートで使われるような図形、ストレージで使われる円筒のような図形もあってよい」(星形はいらない)と要望があった。

## 決定

### D1: 8 種類を足す(合計 13)
| `shape` | 形 | 流れ図での意味 |
|---|---|---|
| `trapezoid` | 上が狭い台形 | (ピラミッドの層、土台) |
| `inverted-trapezoid` | 上が広い台形 | 手作業 |
| `parallelogram` | 平行四辺形 | データ(入出力) |
| `pentagon` | 下が尖った五角形 | 他ページへの接続 |
| `pill` | 両端が丸い箱 | 端子(開始・終了) |
| `rounded` | 角丸の四角 | 処理 |
| `document` | 下辺が波形の四角 | 書類 |
| `cylinder` | 円柱 | データベース・ストレージ |

名前は形(幾何)を表す。意味(`terminator` など)は `flowchart()` の `kind` が持つ。意味は README の表に書く。

### D2: 輪郭の計算を `lib/emblem-shapes.ts` に分ける
`flow-shapes.ts` は、配置・文字の折り返し・描画の入口を持っていて長い。輪郭の幾何(形ごとの高さ・文字の中心・anchor・文字が入る長方形)は、副作用のない純粋な計算なので、別ファイルにした。`flowchart()` が後で同じ記号を持つときに、同じ輪郭を使える。

### D2.5: 高さが文字で決まる形(`pill` / `rounded` / `parallelogram` / `document` / `cylinder`)
最初の版は、全ての形が「幅 D に対する割合の高さ」で、帯の全項目が 1 つの D を共有していた。そのため、端子に `sub` を 1 行足すと(高さ .5D の中に 2 行入れるには D ≥ 126)、**同じ帯の円も含めて全部の形が D=128 になり**、端子に短い行を 5 つ入れると 320×160 になった(レビュー M2。実フォントで再現)。流れ図の端子・処理は横長の箱で、行が増えたら縦に伸びるのが自然なので、この 5 形は**幅 D のまま、高さを文字の行数で伸ばす**。

- `emblemHeight(shape, d, textH)`: 既定の高さと、文字の高さに余白を足した値の大きい方(端子は文字の長方形が高さの .6 なので `textH / .6`、角丸は `textH + .24 D`、平行四辺形は `+ .32 D`、書類は `+ .38 D`、円柱は `+ .45 D`)。4px の格子に切り上げる。
- 折り返しの幅は D の割合のまま(高さに依らない)なので、行数は D だけで決まり、反復は要らない。端子の文字の幅は、高さが D まで伸びても輪郭の内側に入るように .72 D にした(角の円弧の式で確かめた)。
- 高さの上限は、端子が D(円になるまで)、他の 4 形が 1.6 D。それを超えるなら D を広げる。
- 行の高さは、帯の最も高い形(外接矩形の高さ)で、他の形は行の中で縦に中央寄せ。
- 他の形(円・四角・三角形・ひし形・六角形・台形・逆台形・五角形)は、縦横比を保つので、従来どおり D で高さが決まる。

### D3: 輪郭の約束(ADR 0043 D4 と同じ)
- 多角形の頂点は 4px の格子に乗り、縦の中心線について左右対称(平行四辺形は中心について点対称)。幅 D は 8 の倍数なので中心も格子に乗る。
- 曲線を含む形(`pill` / `rounded` / `document` / `cylinder`)は、直線部分と円弧の端点を格子に乗せる。`pill` の半径は `D/4` なので、D が 8 の奇数倍のとき端点が格子から 2px ずれる(lint の `coordinate-grid` は `<path>` を数えない)。
- 文字の長方形は、形の幅 D に対する割合で決める(新しい形: 台形・逆台形 .6×.3、平行四辺形 .56×.28、五角形 .76×.32、端子 .72×.3、角丸 .84×.46、書類 .84×.42、円柱 .84×.4。高さが文字で決まる 5 形の高さは D2.5)。**文字の長方形の角そのもの**を、輪郭までの距離(線の太さの半分を引く前)で測ると、64〜320px の全サイズで 3.3px 以上(平行四辺形は D=72 で 2.9px、端子は D=64 で 2.3px まで近づくことをレビューで確かめた)。実際の文字の箱は長方形より小さく、実フォントでの余白は下の「確認」。
- **anchor は `:top` / `:bottom` / `:left` / `:right` が輪郭に乗る**ように決める。外接矩形のままでよい形(円・四角・ひし形・六角形・五角形・端子・角丸・円柱)と、斜辺の中点を結ぶ矩形(三角形・台形・逆台形・平行四辺形)と、波の中央までの矩形(書類)がある。三角形と同じ理由(外接矩形だと左右の端点が輪郭から浮く)で、検査の障害物は外接矩形(`bounds`)のまま。

### D3.5: 書類の波
波は `Q` と `T` の 2 つの 2 次ベジェで描く。2 次ベジェは制御点まで届かず、中間までしか行かないので、最初の版は制御点を `b - 2a` / `b` にして、波の谷が `b - a/2` で止まっていた(`box` / `bounds` が描いた範囲より最大 12px 大きい。レビュー L1)。制御点を `b - 3a` / `b + a` にして、山を `b - 2a`、谷を `b` に届かせた。テストが、4 つの `path` の形の描いた範囲が `box` と一致することを `flattenPath` で確かめる。

### D4: 塗りのある `path`
`pill` / `rounded` / `document` / `cylinder` は直線と曲線なので、`polygon` では描けない。`FlowPrimitive` の `path` に `fill`(箱の tone)と `box`(描いた範囲)を足し、`polygon` / `circle` と同じ塗り・枠・線種で描く(`danger` / `removed` は破線)。`drawnExtent`(図の幅の判定)は `box` を数える。円柱の手前の縁(リム)は、本体と**同じ向き**の部分パスで描く(逆向きだと、塗りの巻き数が打ち消し合って穴が空く。最初の版で起きた)。

### D5: 輪郭との余白を測る関数 `emblemClearance`
`emblemClearance(shape, left, top, d, q)` は、点が輪郭の内側にどれだけあるか(外側なら負)を返す。曲線は 48 分割で多角形にして測り、円柱のリムは、文字が避ける線として数える。テストが、全 13 形 × 複数のサイズ × 文字の有無で、文字の箱の四隅が輪郭の内側 1px 以上にあることと、anchor の 4 点が輪郭の上(1px 以内)にあることを確かめる。

## 確認(実フォント)
13 形 × 15 種のラベル(長い 1 語・英大文字・絵文字・改行・下に伸びる字形・長い `sub`・端子の `開始 / 受付`・5 行など)× 最小幅 5 通りの 975 通りで、文字の箱の四隅が輪郭の外に出るものは 0 件、検査に引っかかるものも 0 件。最小の余白は 2.29px(既存の六角形)。高さが文字で決まる 5 形は 3.43px 以上、他の新しい形は 5px 以上(余裕を残している)。最大の形は 320×280(長い文字)。

## 見送ったこと・残り
- `flowchart()` の `kind` に、データ・手作業・書類・データベースなどを足すこと(層状の配置では、経路が輪郭に合うように端点を補正する必要がある)。
- 星形・パスで渡す自由な図形。
- 書類の重なり(複数の書類)、円柱の中の線(複数の層)などの記号の細部。
- 台形・逆台形・五角形・三角形・六角形・ひし形は、縦横比を保つので、文字が多いと D が大きくなる(高さが文字で決まる 5 形のようには伸びない)。
- 文字の長方形は保守的で、輪郭の内側に余裕がある(特に `square`・`document`・`cylinder`・`pentagon`)。形が文字に対して少し大きくなる。
- spotlight で暗くした帯の、tone 付きの図形(`emblem` に限らず `funnel` なども)は、塗りが muted に置き換わって文字と同じ色になり、lint が止める(`emit-handlers.ts` の `renderBand`。この PR より前からある不具合で、別に直す)。
