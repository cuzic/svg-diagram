# ADR 0047: `plane()` の `stages` と `evolves` — Wardley Map を描く

- 状態: 実装済み(レビュー前)
- 日付: 2026-10-30
- 基点: `main`(PR #343 まで)
- 関連: ADR 0046(`valueChain()`)、`plane()`(点・補助線・矢印・軸)
- 範囲外: 専用の `wardley()` 帯、依存線の自動配置、点の移動先に自分のラベルを付けること、APQC PCF(`tree` / `table` で足りる)

## 背景
「Wardley Map を描きたい」という要望(戦略図の網羅の見直しから)。試作(`plane` を変えずに描く)では、点・依存線・進化の矢印はほぼ描けた。足りなかったのは、(1) 段階の境目の縦線を `lines` で手書きしている(依存線と同じ部品で、意味が区別できない)、(2) 進化の矢印が点と結びついていない(移動後の位置に点が出ない)、の 2 点だった。他は既存の機能で済む(y 軸の端ラベルは `ticks: [{at, label}]`、依存線は `lines` の `dashed: false`)。

## 決定
### D1: `plane({stages: [...]})`
x 軸を同じ幅の列に分け、列の名前を各列の真ん中の x 目盛りにする。列の境目に破線の区切り(`muted`)を引く。区切りは「線の置き場」の障害物にも数えるので、点のラベルは区切りを避ける。名前は x の目盛りなので、`x.ticks` / `step` / `categories` とは併用できず throw する(2 個未満の名前も throw)。
### D2: `points[].evolves: {to}`
点が x 方向へ進む先。`[to, y]` に薄い輪(`ring`、`muted`)を置き、点から輪の縁(8px 手前)まで破線の矢印を引く(色は点の色)。`to` が点より右で x 軸の内側でなければ throw。段階表示(`reveal`)は点に従う。
### D3: 帯は作らない
依存線の向き(上が下に依存)・段階の数・y 軸の意味は、図ごとに決める。`wardley()` に閉じるのは、この 2 つの形で足りない例が 2 つ出てからにする。

## 結果と残り
- 例 `examples/wardley-map.ts`(golden あり)。テストは `test/plane-wardley.test.ts`。
- 残り: 移動先の輪に名前や id を付ける(`connect()` の端点にする)、点が左へ戻る(逆進化)、段階ごとの背景色、同じ図に複数の `evolves` が重なったときのラベル避け。要望があれば。
