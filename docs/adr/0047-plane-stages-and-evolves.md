# ADR 0047: `plane()` の `stages` と `evolves` — Wardley Map を描く

- 状態: 実装済み(レビュー前)
- 日付: 2026-10-30
- 基点: `main`(PR #344 まで)
- 関連: ADR 0046(`valueChain()`)、`plane()`(点・補助線・矢印・軸)
- 範囲外: 専用の `wardley()` 帯、依存線の自動配置、慣性・パイプライン・調達の塗り分け・市場の記号・番号付きの注記(D3)、APQC PCF(`tree` / `table` で足りる)
- 用語: Wardley Map の縦軸は「value chain」と呼ばれるが、ADR 0046 の `valueChain()`(ポーターの価値連鎖)とは別物。この図の縦軸は「可視性」と書く

## 背景
「Wardley Map を描きたい」という要望(戦略図の網羅の見直しから)。試作(`plane` を変えずに描く)では、点・依存線・進化の矢印はほぼ描けた。足りなかったのは、(1) 段階の境目の縦線を `lines` で手書きしている(依存線と同じ部品で、意味が区別できない)、(2) 進化の矢印が点と結びついていない(移動後の位置に点が出ない)、の 2 点だった。他は既存の機能で済む(y 軸の端ラベルは `ticks: [{at, label}]`、依存線は `lines` の `dashed: false`)。

## 決定
### D1: `plane({stages: [...]})`
x 軸を名前つきの列に分け、列の名前を各列の真ん中の x 目盛り(目盛りの線は付けない)にする。列の境目に破線の区切り(`muted`)を引く。
- 幅は既定で等しい。**`{name, to}` で列の右端の x を書ける**(最後の列以外はすべて書く。増える順で軸の内側。最後の列は軸の端まで)。OnlineWardleyMaps などは境目が等間隔でないので、写すときに要る。
- 区切りは「線の置き場」の障害物にも数える。**自動で置くラベルは区切りを避ける**。`labels` や `labelAt` を書いた点のラベルが区切りに触れると、検査が `overlaps a stage divider` で止まる(列の境目をまたぐ注記は `offset` / `anchor` でずらす)。
- `grid: true` のときの縦線は、区切りの位置に引く(列の真ん中ではない)。
- `lines` の `dashed` の既定は、`stages` があると `false`(実線)。依存線が区切りと同じ破線に見えないようにする。
- 名前は x の目盛りなので、`x.ticks` / `step` / `categories` とは併用できず throw する(2 個未満の名前、`to` の不揃い・逆順・最後の列の `to` も throw)。長い名前は折り返さない(幅が足りなければ検査がラベルの重なりで止める。図の幅を広げる)。
### D2: `points[].evolves: {to}`
点が x 方向へ進む先。`[to, y]` に薄い輪(`ring`、`muted`)を置き、点から輪の縁(輪の手前、最大 8px)まで破線の矢印を引く(色は点の色)。`to` が点より右で x 軸の内側でなければ throw。段階表示(`reveal`)は点に従う。
検査: 点から輪までが 24px 未満(矢印が読めない)、輪が別の点・別の輪に 14px 以内、別の点が矢印の上にある、のどれかなら、検査が止まる(layout が `clashes` に入れ、`checkPlane` が出す)。アンカーの印(例では `diamond`)と輪は形でも区別できる。
### D3: 帯は作らない — ただし `evolves` は仮置き
`stages` は汎用の「名前つきの列」で、Wardley 専用ではない。`evolves` は右向き・y 固定・muted の輪という、Wardley の意味が入った部品で、汎用の plane に置くのは仮置きとする。
**きっかけ**: 次の Wardley 固有の部品を plane に **1 つでも** 足したくなったら、`wardley()` に閉じる(`evolves` も移す)。
- 慣性(点の右の太い縦棒)、パイプライン(進化の範囲にまたがる枠と、その中の部品)、名前を変える進化(OWM の `evolve A->B`。移動先の輪に名前・id を付ける)、調達の塗り分け(build / buy / outsource)、市場・エコシステムの記号、番号付きの注記
いまは、これらが無くても描ける最小の図(試作)のために 2 つだけ足す。

## 結果と残り
- 例 `examples/wardley-map.ts`(golden あり)。テストは `test/plane-wardley.test.ts`。
- 残り: `evolves: {to, reveal?}`(発表で「今の地図 → 進化の予想」と順に見せる)、`PlanePoint.until` が描画に届いていない(この PR の前から。直すときは輪と矢印も)、逆進化(左向き)、`to` が軸の端のとき、点・輪・矢印と依存線の重なり(依存線が輪を通る件は検査なし)、段階ごとの背景色、`as const` でない型の細部。要望があれば。
- Opus レビュー(1 巡目): 高 2・中 6・低 8 を受けて、`{name, to}`、D3 の条件、`grid`・目盛り・`lines` の既定・重なり・短い矢印の検査、ADR の追記を入れた。
