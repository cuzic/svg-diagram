# ADR 0048: `swimlane()` の `boundaries` — サービスブループリントの線

- 状態: 実装済み(レビュー前)
- 日付: 2026-10-30
- 基点: `main`(PR #345 まで)
- 関連: ADR 0047(Wardley Map を plane の拡張で描いた前例)、`swimlane()`、`journeyMap()`(ステージ×レーン、感情曲線つき)
- 範囲外: 専用の `serviceBlueprint()` 帯、レーンの固定 5 本の preset、レーンの間に引く線の種類ごとの見た目の違い、時間の軸(列)に引く線、`journeyMap()` との統合

## 背景
サービスブループリントは、顧客の行動を上に、表の業務(接点)、裏の業務、支援システムを下に並べ、レーンの境目に 3 本の線(相互作用線・可視線・内部相互作用線)を引く図。「顧客体験を裏側でどう実現しているか」を見せる。試作(`swimlane()` を変えずに描く)では、5 レーン(物的証拠・顧客の行動・表の業務・裏の業務・支援システム)と、縦にまたぐ矢印は描けた。足りなかったのは、境目の線とその名前だけだった。レーン名に「(可視線の上)」と書く手は、線が見えないので図として弱い。

## 決定
### D1: `swimlane(lanes, steps, {boundaries: [{after, label?}]})`
レーン `after` と次のレーンの境目に、太い破線(3px、`10,6`)を全幅に引く。`label` があれば、境目をまたぐ丸いチップ(ラベル列の幅 − 16px、1 行)にその名前を書く。線は既存のレーンの区切り(2px の実線)の上に重ねる。色だけでなく太さと破線で区別でき、白黒でも読める。
### D2: チップの分だけレーンを高くする
ラベルのある境目の両側のレーンは、レーン名(中央寄せ)がチップに触れないように、高さを「レーン名の高さ + チップの高さ + 4px」以上にする(チップの高さは `boundaryChipH(note)`)。レーンの高さが変わるので、境目を書いた図は、書かない図と高さが違う。境目を書かなければ出力は 1 バイトも変わらない。
### D3: 検証
`after` がレーンの id でない・最後のレーン・同じレーンに 2 本・ラベルが空、は throw。`laneOrder` とは併用できず throw(レーンが動くと、境目の意味が変わる)。ラベルがラベル列に 1 行で入らなければ throw(短くする、`labelW` を広げる)。
### D4: 帯は作らない
レーンの数・名前・線の本数は図ごとに違う(物的証拠を置かない、線を 2 本にする、など)。専用の帯は、`boundaries` で足りない例が出てからにする。PPTX は swimlane と同じく画像で書き出す。

## 結果と残り
- 例 `examples/service-blueprint.ts`(golden と PPTX golden あり)。テストは `test/swimlane-boundaries.test.ts`。
- 残り: 線ごとの見た目の違い(可視線だけ太く、など)、境目のチップを右端に置く選択、時間軸(列)に引く線(「注文前 / 注文後」は `phases` で足りる)、`reveal` で線を段階的に出す。要望があれば。
