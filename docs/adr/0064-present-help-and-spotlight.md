# ADR 0064: `?` でショートカットキーの一覧と、スポットライト

- 状態: 実装済み(2026-11-15、利用者の決定)
- 基点: `feat/deck-serve`(ADR 0063 まで、未コミット)
- 関連: ADR 0062(画面の操作)、ADR 0063(拡大縮小と調査。「次に作る候補」の 3 と 6)

## 背景

ADR 0063 の調査で挙げた候補のうち、利用者は「`?` でショートカットキーの一覧」と「スポットライト」を選び、ほかは作らないと決めた(2026-11-15)。どちらも調べたツールに例がある。

- `?` の一覧: Keynote、reveal.js、pdfpc、Canva にある。
- スポットライト: pdfpc にある。

## 決定

- D1. **`?` でショートカットキーの一覧**を重ねて出す。
  - 聴き手と発表者の画面で中身が違う。聴き手には連動・レーザーなどの発表者のキーを出さない。
  - 分類ごと(スライド・聴き手・指す・拡大・時間・画面)の表にする。
  - `?`・Esc・外側のクリックで閉じる。聴き手の操作バーにも「?」のボタンを置く。
- D2. **スポットライト**(発表者だけ)。
  - `s` かボタンで入れると、スライドの上のマウスの周りの円だけが明るく、ほかが暗くなる。
  - 円の大きさは `[` / `]` で変える(スライドの幅の 4〜40%、既定 12%、端末に覚える)。
  - レーザーとは、どちらか一方だけ(入れると、もう一方は切れる)。
- D3. **聴き手への同期**:
  - レーザーと同じ `pointer` に `spot: true` と半径 `r`(スライドの幅に対する割合、0.03〜0.5)を足して送る。保存せず、1 秒 30 回まで。
  - 同じスライドを見ている聴き手の画面に、同じ所・同じ大きさで出る(拡大していても、拡大した画像の上で同じ所)。
  - 連発した最後の位置は、50ms の間隔の後で必ず送る。止めたときの位置が聴き手とずれない。

## 確かめたこと(nov18 の写し、Chromium、自動の操作で 14 項目)

- 一覧:
  - 聴き手で `?` を押すと一覧が出て、聴き手のキーだけが並ぶ。
  - Esc、「?」のボタン、外側のクリックで開け閉めできる。
  - 発表者の一覧には、`k`・`l`・`s`・`[ / ]`・`t` が並ぶ。
- スポットライト:
  - 発表者の画面と聴き手の画面に出て、聴き手ではレーザーの点は出ない。
  - `]` を 2 回押すと、聴き手の円も 1.44 倍になる。
  - `l` でレーザーに切り替わり、もう一度で両方が消える。拡大中も出る。
- 自動テスト: 形と範囲(`test/present-sync.test.ts`)、手元のサーバーが聴き手に届けること(`test/serve-cli.test.ts`)。Worker は `pointer` をそのまま渡すので、ADR 0062 のテストで足りる。
