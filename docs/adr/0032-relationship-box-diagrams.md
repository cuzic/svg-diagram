# ADR 0032: 「箱」の人間関係の図は、新しい帯を足さず、例とレシピで描く

- 状態: 決定(帯は作らない)。当初は `collusion` / `boxIceberg` の 2 帯を提案し、U0 の試作と Opus レビュー(第 1 回: blocker 2 / major 7 / minor 9)を経て取り下げた
- 日付: 2026-10-17
- 基点: `main`(85e468e)
- 関連: ADR 0025(新しい帯を足す費用の前例)、ADR 0031(`lib/` は core)、`skills/svg-diagram/references/relationship.md`(レシピ)

## 背景

人間関係の自己欺瞞を扱う書籍の図(共謀・箱の中/外・自己正当化のイメージ・箱から出る流れ)を描きたい。図ごとの専用の帯を作るか、既存の帯で描くかを決める。

## 検討(実測)

U0 を 2 回やった(`proto/`、コミットしない作業用)。

| 図 | 既存の部品での結果 |
|---|---|
| 共謀(二人の循環) | **`cycle` が書籍の 4 点の円をそのまま描く**(見方・行動 × 2 人)。1 回目は `group` + `connect` で試して矢印が箱に重なったが、`cycle` を試していなかった。`check --strict` は警告なし。節の文は短く(約 12 字 × 2 行)しないと円の中で折れる |
| 氷山(同じ行動、違う心の向き) | `banner` + `row` + `group` で描ける。凡例の意味が逆に読めたのは、`danger` / `removed` を「箱の中」に使った選択の誤り。意味に合うトーン(`plain` / `muted`)と `diagram({legendLabels})` で直る。残る穴は「水面が箱であって線でない」だけで、他の図にも出る一般の欠け |
| 自己正当化イメージの型 | `table` で足りる |
| 箱から出る流れと戻り | `chevron({loopBack})` で足りる |

Opus レビューの指摘(`cycle` / `causalLoop({layout: 'ring'})` が使える・凡例と読む順は `legendLabels` と `step:` で直る・帯を足す配線の表が実際より少ない・PPTX は `'image'` 分類・検査の規則の重大度と ID の登録の仕組み)は、帯を作る案の前提を崩すものだった。

## 決定

1. **新しい帯は作らない。** `collusion` / `boxIceberg` / `imageMap` / `wayOut` はいずれも作らない。
2. **例とレシピを足す。** `examples/arbinger-*.ts`(4 枚。golden に入れる)と `skills/svg-diagram/references/relationship.md`(SKILL.md の領域別の案内から 1 段)。
3. **例の場面は説明用の架空にする。** 書籍の逸話(登場人物・場面)は写さない。用語(型の名前など)は書籍の訳語で書くよう案内し、例は「用語は書籍で要照合」と出典行に明記する。

## 帯に戻す条件

次のどれかが出たら、新しい ADR で帯を検討する(「同じパターンが 3 回出たら部品にする」の原則)。

- 同じ配置の手順(例: 二人の循環に、箱の中/外の枠と側注を付ける)を、3 つ以上の別の図で手書きした。
- 検査で止めたい約束(例: 箱の外の人に自己正当化を書かない)が、運用で破られて実害が出た。ただしその約束は書籍の主張の代弁になるので、型の throw ではなく、注意の検査(`info` / `warn`、`accept` で許容)にする。
- 水面のような**横線**が他の図でも要る。これは特定の題材に専用でなく一般の部品(divider)として別に決める。

## 帯を作る場合に守る点(レビューの記録)

将来の ADR のために、第 1 回レビューの指摘を残す: (a) 配置は具体的に決める(同じ順で縦に積むと矢印が箱を貫いて止まる。循環は 4 点の `cycle` が書籍に近い)。(b) 凡例は `DEFAULT_LEGEND_LABELS` / `usedNotation` / 凡例の見本の種類まで配線する。(c) 検査の規則は `RULE_DOCS` に登録し、重大度は `warn` / `info`。(d) 配線の表は `fta` が触った箇所を数える(`band-ids` / `band-table` / `dsl/render` / `emit-boxes` / `pptx/bands` / `untested-exports.json` ほか)。(e) 「心の向きは特定の相手・時点に対するもの」なので、箱の外の人に正当化を持たせない型の throw は書籍の読みとして強すぎる。
