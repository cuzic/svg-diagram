# ADR 0062: 聴き手と発表者の画面の操作(Slidev の機能を調べ直して足す)

- 状態: 実装済み(2026-11-15。利用者の決定に従う)
- 基点: `feat/deck-serve`(687d1ce、ADR 0061 まで)
- 関連: ADR 0056(`serve`。D4・D6・D7・D8・D18 を、この ADR で変える)

## 背景

`serve` の聴き手の画面には、全画面のボタンしかなかった(nov18 で確かめた)。ADR 0056 の決定どおりで、理由は次のとおり。

- D6: 全端末を発表者のスライドに強制的に合わせ、聴き手は動かせない。
- D8: 聴き手には全画面だけ。
- D18: そのほかは見送り。

利用者は「Slidev の機能を調べて作る」つもりだったので、前へ・次へもない画面に落胆した(2026-11-15)。そこで Slidev の公式の文書(sli.dev。`/guide/ui`、`/features/remote-access`、`/features/timer`、`/features/drawing` と、文書全体の `llms-full.txt`)で機能を調べ直し、作るものを決め直した。

## 利用者の決定(2026-11-15)

- **聴き手の動き**: 「発表者側で連動操作をしたら、必ず連動する。そうでなければ、自由に動かせる」。
  - 発表者の画面に「連動」の切り替えを置く(既定は入)。
  - 連動が入っている間は、発表者が動かすたびに、すべての聴き手が発表者のスライドに移る。別のスライドを見ていた聴き手も移る。
  - 切ると、発表者が動かしても聴き手は動かない(発表者が先を確かめる、など)。ただし、発表者と同じスライドにいる聴き手は付いてくる。
  - 聴き手は、いつでも自分で動ける。「発表者に合わせる」ボタンで、発表者のスライドに戻れる。
- **先のスライド**: 全部見せる。聴き手にも全スライドの URL を渡す(ADR 0056 の「聴き手には今のスライドだけ」をやめる)。ノートは今までどおり発表者だけ。

## Slidev の機能と、ここでの扱い

| 機能(Slidev) | 扱い | 理由・中身 |
|---|---|---|
| キー(→ space ← ↑ ↓ Home End) | **作る** | 聴き手と発表者の両方。PageUp / PageDown も |
| 操作バー(マウスで出る) | **作る** | 聴き手: ‹ › 番号 一覧 全画面 印刷 発表者に合わせる。マウスを動かすか、画面に触れると 2.5 秒出る |
| スワイプ、ホイール | **作る** | ホイールは 0.6 秒に 1 回 |
| 番号へ移動(`g`) | **作る** | |
| スライドごとの URL | **作る(`#3` の形)** | Slidev は `/3`。ここはサーバーの URL を増やさず、ハッシュにする。`/#7` で開くと 7 枚目から(自分で動いた扱い) |
| 進み具合のバー、ページ番号 | **作る** | 聴き手の画面の下に細い線 |
| 一覧(`o`) | **作る** | 聴き手も。発表者のスライドは青、自分のスライドは橙の枠 |
| 全画面(`f`) | 作ってある | |
| ダークモード(`d`) | 作らない | スライドは図の検査のとおりに明るい形で描く(ADR 0056 D2)。周りはもともと暗い |
| 窓の同期(発表者に付いてくる) | **変える** | 上の「連動」 |
| 発表者の画面: 今・次・ノート | 作ってある | |
| タイマー(開始・一時停止・0 に戻す) | **作る** | `t` で開始・一時停止、`r` で 0 に。今までは 0 に戻すだけ |
| 時間の配分(Slidev の `duration`、進み具合) | **作る** | 予定の分(既定 30、端末に覚える)に対して、時間と今のスライドを 2 本の帯で比べ、「予定より n 分早い/遅い」と出す |
| 時計 | 作ってある | |
| 発表者の画面の配置(3 種類) | 見送り | 狭い画面では縦に並ぶ。配置を選ぶ必要はまだない |
| 画面の映し込み(Screen Mirror) | 見送り | 聴き手の画面を別窓で開ける(`p`) |
| ノートの編集(`/notes-edit`) | 見送り | ノートの元は deck.json。ブラウザから書き戻すと、エディタで開いているファイルとぶつかる |
| 描き込み(ペン) | 見送り | 同期する描き込みは、保存と消し方まで決める必要がある。まずレーザーで足りるか見る |
| レーザーポインター | **作る** | 発表者が `l`(またはボタン)で入れ、スライドの上でマウスを動かすと、同じスライドを見ている聴き手に赤い点が出る。1 秒 30 回まで送る |
| 段階表示(v-click) | 作らない | デッキの JSON に段階がない(ADR 0056 D18 のまま) |
| 切り替え効果 | **作る(短いフェード)** | 0.18 秒。`prefers-reduced-motion` では切る |
| 録画、カメラ | 作らない | OS とブラウザの画面録画で足りる。カメラを足すと、権限と取り扱いが増える |
| PDF / PNG の書き出し | **作る(印刷)** | 聴き手にも印刷ページ(`/print`)を開いた。ブラウザの印刷で PDF にできる。.pptx は発表者だけ(手元の `/deck.pptx`) |
| 携帯から操作(リモコン) | **作る** | 発表者の画面は、狭い画面で大きな「‹ 前」「次 ›」のボタンとスワイプで動かせる |
| 発表者のパスワード(`--remote`) | 作ってある | 発表者のトークン、Worker ではメールアドレス(ADR 0056 D9、D13) |
| 画面を消さない(Wake Lock) | **作る** | 対応するブラウザで、表示している間 |
| カーソルを隠す | 作ってある | 2 秒 |
| CSS フィルター、1:1 表示 | 作らない | 図の色はスライドに合わせて決めている |

## 決定

- D1. **やりとり**(`lib/present/sync.ts`)。送り受けの決まりの版を **2** にする。`--publish` と Worker の版が違えば、送る前に止まる。
  - 状態に `linked`(連動)を足す。
  - 発表者が送るものに、次の 2 つを足す。
    - `{type: 'link', on}`: 連動を入れる・切る。状態の `seq` を増やす。連動を入れると、その時点で全員が発表者のスライドに移る。
    - `{type: 'pointer', index, x, y}` / `{type: 'pointer', off: true}`: レーザー。位置は 0〜1。保存しない。
  - 聴き手が送ったものは、今までどおり捨てる。
- D2. **聴き手にも全スライド**。デッキ(全スライドの URL・題・文)を、聴き手にもつないだときと版が変わったときに送る。印刷ページも聴き手に開く。ノートと `/deck.pptx` は発表者だけ。
  - ADR 0056 D3 の「聴き手には今のスライドの URL だけ」と、D6 の「今の版にあるハッシュだけを返す」のうち前半を変える。今の版にないスライドが 404 なのは変わらない。
- D3. **聴き手の画面**(`lib/present/ui.ts`)。
  - 聴き手は、自分の位置と「発表者に付いているか」を持つ。
  - 連動が入っていて発表者が動かしたら、付いているかに関わらず発表者のスライドに移り、付いている状態に戻る。
  - 連動が切れていれば、付いている聴き手だけが移る。
  - 自分で動いたら付いていない状態になる。発表者のスライドに戻れば付いている状態に戻る。ボタン(`b` か Enter でも)で戻る。
- D4. **発表者の画面**: 大きな前・次のボタン、連動(`k`)、レーザー(`l`)、タイマー(`t` / `r`)、予定の分と進み具合。
- D5. ADR 0056 の D6(強制の追従)・D7(発表者の操作)・D8(聴き手には全画面だけ)・D18(見送り)は、この ADR で置き換える。D9・D13(発表者の見分け)は変えない。

## 確かめたこと(nov18 の写し、37 枚、手元の `serve`、Chromium)

自動で操作して 23 項目を確かめ、ページの例外はなかった。

- 聴き手は、最初は発表者のスライド。→ 2 回で 3 枚目に動き、発表者は動かない。「発表者に合わせる (1)」が出て、URL は `#3` になる。
- 連動の間、発表者が → を押すと、3 枚目にいた聴き手も 2 枚目に戻る。
- 連動を切り、聴き手が End で最後へ。発表者が → を押しても、聴き手は最後のまま。ボタンで発表者のスライドに戻る。
- 一覧は 37 枚で、選んだスライドに移る。ホイールで次へ。携帯の幅でスワイプで次へ。`/#7` で開くと 7 枚目。
- レーザー: 発表者がスライドの上でマウスを動かすと、聴き手に赤い点が出て、切ると消える。
- タイマー: 開始・0 に戻すが動き、進み具合の文(「予定より 2 分早い」)が出る。
- 聴き手から印刷ページが開ける。携帯の幅の発表者の画面で「次 ›」を押すと、聴き手も移る。
- 自動テスト:
  - 手元: 連動・レーザー・聴き手からは送れないこと(`test/serve-cli.test.ts`)、やりとりの形(`test/present-sync.test.ts`)。
  - Worker: 連動とレーザーが WebSocket で届くこと、聴き手のものは捨てられること(`worker/test/worker.test.ts`。全 16 件)。
