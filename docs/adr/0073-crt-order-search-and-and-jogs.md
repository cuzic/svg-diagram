# ADR 0073: CRT の並びの探索(高さ・並走の組・打ち切り)、AND の矢印の段差、D12〜D14 の整理、`edge-parallel` の範囲

- 状態: 提案(Draft。2026-11-21。決める人の判断が要る点は「論点」に書いた)
- 日付: 2026-11-21
- 基点: `main`(PR #402 まで)。数値はすべて ADR 0070「U6 測定結果」(同じ PR)の測定による
- 関連: ADR 0070(CRT の辺の読みやすさ。U6 の残り)、ADR 0019 D4(並びの再探索)、ADR 0053(探索の費用)、ADR 0016 D12〜D14(並走のずらし)、ADR 0015(AND の弧)、Issue #397(探索が高さを見ない)
- 範囲外: 層の中の並びを直接探す新しい探索(論点 Q3)。pdpc・relationDiagram・whyWhyTree へのトラックの広げ(ADR 0070 の未決)。隙間のトラック数での隙間の大きさ(D4)。`causeTree` 以外の図の出力は変えない(探索は `causeTree` の帯だけ。pdpc・relationDiagram・whyWhyTree と states・classes・semnet・bpmn の golden の差分は 0)

## 背景

ADR 0070 の U0〜U5 で、報告の図(fixture)は完了の基準を満たした(折れ ≤ 4、`cause-crossing` 0、倍率の線の間隔の組 0、間隔 ÷ `minText` = 1.0)。U6 の測定で、残りは次のとおりと分かった(乱数の CRT: 幅 1800 の 138 枚 / canvas 倍率 1.29 の 80 枚。main との図ごとの比較)。

| # | 残り | 測定 |
|---|---|---|
| 1 | 順序探索の高さのふるいが、交差の少ない候補を捨てる(Issue #397) | 幅 1800 で 14 枚、canvas で 10 枚の図に、より良い候補があった。外すと交差 344 → 320・183 → 172 |
| 2 | 並走の組が図ごとに悪化することがある(U5 の注記) | `better()` に組が無い。(交差, 組, 折れ)にすると組 43 → 38・30 → 25、折れ +1.3%・+0.2% |
| 3 | AND の矢印の段差(報告の図の点 2) | `align` が AND の矢印を直線にしない。fixture で 2 本(1 口分 = 28px) |
| 4 | D12〜D14 | D14 は最終の図を動かさない。D12・D13 は 2 + 1 枚を探索への入り口の条件を通して動かす。費用の差は無い |
| 5 | 探索の打ち切り・層の検査・トラックの隙間の大きさ | 打ち切りは 96% の図で効くが、外すと 60 節で ×3.9 の費用。層の検査は main で 0 個しか捨てない。トラックの隙間は実 CRT で得が無い |
| 6 | `edge-parallel` を他の図へ | relationDiagram 68%・pdpc 19%・whyWhyTree 0% |

## 論点

- **Q1(高さ)**: 図が高くなってよいか。交差が減るなら、高さを何 % まで払うか(10%・25%・50%)。
- **Q2(組)**: 並走の組を減らす代わりに、折れが +1〜2% 増えてよいか。
- **Q3(層の並び)**: 層の並びそのものを探す探索(焼きなまし)を、別の ADR で入れるか。fixture の点 1(5 つの交差)は、いまの探索では減らない。
- **Q4(利用者に確かめる)**: 点 4(箱の左上の縦の線)がどの線かを、利用者に確かめるか。

## 決定(案)

### D1: 順序探索の採点とふるい

選択肢:

| 案 | 内容 | 測定 |
|---|---|---|
| A | 今のまま(高さ ≤ base + 0.5px、座標の検査、打ち切り) | 基準。14 + 10 枚で良い候補を捨てる |
| B | 高さのふるいを外す | 交差 344 → 320(7 枚)・183 → 172(5 枚)。高さ +490px(13 枚、最大 +87px = +19%) |
| **C(推奨)** | **高さと交差の交換**: 基準より高い候補は、**(AND の交差, AND の並走, 交差)の 3 つ組が厳密に減る**ときだけ採り、高さの増えは +25% まで。ふるいを通る候補・最終の選びの両方に同じ規則 | B と同じ利得(344 → 320、183 → 172、`cause-crossing` 35 → 29・19 → 16)。高さが増える図は 11 + 8 枚(+0.55%)。費用は増えない(60 節 2.2s、120 節 4.2s) |
| D | C を +10% までに | 344 → 323・183 → 174。#106(+24%)・#75(+19%)が残る |

- 推奨は C。**+25% は暫定で、論点 Q1**。canvas の高さの予算(`heightBudget`)は今までどおり効く(予算を超える候補は `NoFit` で落ちる)。折れだけが減る候補は、高さが増えるなら採らない(高さを折れと交換しない)。
- **層の座標の検査**は、座標の値でなく**層の順位**(座標の値を 0.5px 刻みで並べた順位)で比べる。main では捨てる候補が 0 個で出力は変わらないが、隙間の大きさが並びで変わる実装(トラックの隙間など)でも壊れない(U4c の #7・#33)。
- **打ち切り**(`PATIENCE`・`PATIENCE_QUIET`・`MAX_ORDERS`)は**今のまま**。外すと 60 節で 2.2s → 8.5s(×3.9)、交差の利得は −3%(344 → 335)。飛ばした並びを数えない版も、費用(60 節 3.2s・120 節 10.8s)に見合わない。
- **予想(`proxy`)のふるい**は今のまま(外しても 1 枚しか変わらず、費用だけが増える)。
- 採点の key の順は変えない(AND の交差、AND の並走、交差、折れ。D2 で組を足す)。高さを最後の key にする案は、交換(C)より利得が小さい(試した: 交差 −7% は同じだが折れ・組が増える図が増える)ので採らない。

### D2: `better()` と探索の採点に、並走の組を入れる

選択肢: (a) 入れない(今)。(b) (交差, 折れ, **組**)の順(第 3 のキー)。(c) (交差, **組**, 折れ)の順。

| 案 | 幅 1800: 組 / 折れ | canvas: 組 / 折れ | 図ごと |
|---|---|---|---|
| (a) | 43 / 3770 | 30 / 2190 | — |
| (b) | 42 / 3770 | 30 / 2190 | 組 ↓1 だけ。ほとんど効かない |
| **(c)(推奨)** | 38 / 3820(+1.3%) | 25 / 2194 | 組 ↓7 ↑1(幅 1800)、↓4 ↑0(canvas)。折れ ↑6 ↓1 |
| (c) を探索の採点だけ | 41 / 3774 | 27 / 2192 | 組 ↓2、↓3。折れの増え +4、+2 |

- 推奨は (c) を `pick0`・`worse`・`apartOf` の `better()` と、探索の `scoreOfCause`(AND の並走の次、交差の後)の**両方**に入れる(D1 の C と合わせると、組 43 → 40・30 → 22。交差は図ごとに増えない)。組は**その図の倍率の線の間隔**(`laneStepOf(space × scale)`。幅 1800 で 14px、canvas で 18px)で数える。
- **折れが増える図がある**(+1〜2%。論点 Q2)。(b) は安全だがほとんど効かないので、採るなら代替の弱い版(「探索の採点だけ」)。
- 注意: 探索の道が変わるので、図ごとに交差が増えないことを、乱数の分布で確かめる(U2 のテスト。(c)+D1 の C で交差が増える図は 0)。

### D3: AND の矢印の段差(点 2)

選択肢: (a) 今のまま(段差 28px)。(b) `align` に AND の矢印も通す(両方の口を 1 つの高さに寄せる)。**(c)(推奨)頭の口は動かさず、尾の口だけを頭の高さへ寄せる**(`align(i, tailOnly)`)。

| 案 | fixture | 乱数(折れ / 図の数) | 弧・口 |
|---|---|---|---|
| (a) | 折れ 56、段差 2 本 | — | — |
| (b) | 折れ 50、段差 0 | −68(29 枚)/ −42(18 枚) | 頭の口の間隔が一部変わる(最大 103 → 116) |
| (c) | 折れ 52、段差 0 | −58(26 枚)/ −40(18 枚) | 弧の隙間 10.2px・切れ目 30px・口の間隔 28px が**変わらない** |

- 推奨は (c): D3(ADR 0070)の口の間隔と D8 の弧を変えず、段差だけを消す。採る条件は直接の矢印と同じ((交差, 折れ)が厳密に良くなる、`alongOther` でない、`gainsRunPairs` でない)に、**AND の中の交差が増えない**を足す。尾の口の順(隣の口との間隔)を壊す動きは採らない(例: fixture の e3 → u2 は、口の順を壊すので段差のまま)。
- 乱数での損は無い: 交差・`cause-crossing`・`loose` が図ごとに増えない。組は canvas で ↑2 ↓1(U2 と合わせて測り直す)。高さは 1 枚が増える(探索の道が変わる)。
- `examples/toc-*` の 8 枚で折れが −2〜−4(golden が動く)。

### D4: トラックで隙間の大きさを数える(`trackLoad`)

**採らない**(ADR 0070 U4c の保留の結論)。順序探索を直した上で測った:

- `corridorLoad` を `trackLoad` に: 層の座標の検査のままでは #7(交差 1 → 5)・#33(7 → 16)が悪化し、1 枚が幅に収まらずエラーになる。層の順位の検査では、136 / 137 枚が同じで、**ほぼ何も変えない**(実 CRT で隙間は広がらない)。
- `crowdOf` を `min(trackLoad, 今までの数)` に: 組が増える図が 3 枚(#85・#117・#142)。組を比べても 2 枚が残る。97 / 138 枚で点が数 px 動く。「図ごとに悪化 0」を満たせない。

得が無く、図ごとの単調性も満たせないので入れない。**層の順位の検査(D1)だけ入れる**(将来、隙間の大きさが並びで変わる実装を入れても探索が壊れないように)。

### D5: D12〜D14(`shiftOf`・`turnAt`・`moveApart`)

- **D14 は外す**(最終の図に効かない。幅 1800 の 138 枚・canvas 80 枚で、止めても経路が同じ(配置を固定すると canvas で 1 枚が数 px 動くだけ)。費用も変わらない)。`route-apart.ts`・`apartOf`・`AttemptOpts.apart` と、そのテストを消す。
- **D12・D13 は、U1〜U2 を入れた後に測り直して外す**。今は探索に入る条件(`movedAside`)を通して #26(交差 4 → 7 になる)・#42 に効いており、いま外すと悪化する図が出る。探索を直した版(U1・U2 入り)で止めて、図ごとに悪化が 0 なら外す。外せないなら残す(外せない理由を ADR 0070 に書く)。

### D6: `edge-parallel` を他の図へ広げない

relationDiagram 68 / 100 枚・pdpc 19 / 100 枚で指摘が出る(`causeTree` は 3 / 100)。この 2 つは D3・D4(トラック)が効かない図で、近い run はポートの間隔から来る設計どおりの形なので、**利用者が直せない指摘になる**。whyWhyTree は 0 / 98 枚で、広げても何も出ない。広げるなら、ADR 0070 の未決(D3・D4 を pdpc・relation に入れる)を先に決める。`origin` の検査は今のままにする。

## 代替案

| 案 | 採らない理由 |
|---|---|
| 高さのふるいを外す(D1 の B) | 交差の利得は同じだが、交差の減らない候補でも高くなる図が出る(折れだけが減る候補など) |
| 打ち切りを外す・待ちを伸ばす | 費用が ×3.9(60 節)で、交差の利得は −3% |
| 層の座標の検査を外す | 検査が守るもの(循環の切り方が変わらない)を失う。順位で比べれば足りる |
| 組を比べる(D2)を第 3 のキーにする | ほとんど効かない(組 43 → 42) |
| AND の頭の口も動かす(D3 の (b)) | 頭の口の間隔が変わり、D3(ADR 0070)・D8 の弧の前提を動かす |
| 隙間の大きさをトラックで数える(D4) | 実 CRT で得が無く、図ごとの単調性も満たせない |
| 層の並びそのものを焼きなましで探す(Q3) | この ADR の範囲を超える。層の間の交差の下限は fixture で 2 まで下がるが、ポートと AND の弧を含む経路の交差で同じかは未確認 |

## 影響

- **変わる出力**: D1: 順序探索で、より交差の少ない並びが採られる図(幅 1800 の 7 枚、canvas の 5 枚など)。高さが増える(最大 +25%)。D2: 経路の選び方(組の少ない方)が変わる図。D3: AND の頭へ入る直接の矢印(段差のある矢印)が直線になる(`examples/toc-*` の 8 枚の折れ −2〜−4。golden の更新)。D5: D14 を外す(出力は同じ。D12・D13 は測り直し)。
- **変わらない出力**: pdpc・relationDiagram・whyWhyTree、states・classes・semnet・bpmn(探索・`better()` の変更は `causeTree` の帯だけ。golden の差分 0 を各 PR で示す)。canvas の無い図でも、D1〜D3 は動く(CRT の既定のまま)。
- **費用**: D1 は増えない(測定: 60 節 2.2s・120 節 4.2s)。D2 は計算の分だけ増える(組の数え方。60 節 1.7〜2.2s・120 節 4.4s の範囲で、差は測定の幅内)。D3 は増えない(2.16s・4.35s)。D5 で D14 を外しても差は無い。
- **リスク**: D1 で図が高くなり、canvas の高さの予算を使い切る図が出る(予算を超える候補は落ちる)。D2 で折れが増える図(+2 単位)が出る。D3 で golden が動く。

### テスト方針

- ADR 0070 のテスト方針に従う(フォントに依存する絶対値を使わない。数・順序・大小・比較)。
- U1: (1) 小さい図で、高さが +25% 以内で交差が減る並びが採られる(`cause-crossing` が減る)。(2) +25% を超える並び、交差が減らず折れだけが減る並び、高さが増えるだけの並びは採られない。(3) 層の順位の検査: 隙間の大きさが違うだけで層の同じ 2 つの配置を、同じ層とみなす(純関数の単体)。(4) 予算を超える候補は落ちる(`heightBudget`)。(5) 探索に入らない図(交差 0)と、pdpc・relationDiagram・whyWhyTree の点列が変わらない。(6) 乱数の CRT(幅 1800 の 150 枚・canvas 80 枚。`scripts/crt-u6-measure/random-crt.ts` の分布)で、**交差・AND の交差が main より増える図が 0**、高さが +25% を超える図が 0。
- U2: 同じ配置で、組が (交差, 組, 折れ)の順で選ばれる(合成した 2 案)。乱数の分布で、交差が増える図 0、組が増える図の数と合計を PR で報告する(測定: D1 の C と合わせて、幅 1800 で 4 枚、canvas で 2 枚が残る見込み)。折れの合計の増えが +2% 未満。
- U3: fixture の pre2 → e1・r4 → u5 が直線になる(各矢印の折れ 0)。D3・D8 の値(口の間隔 `portStep`、弧の見える隙間、弧の切れ目)が変わらない。AND の中の交差・`loose` が増えない。尾の口の順が逆になる矢印(fixture の e3 → u2)は段差のまま。乱数の分布で図ごとの交差 0 増。
- U4: D14 を外した出力が、外す前と同じ(乱数の分布・fixture・`examples/toc-*`)。D12・D13 は、U1〜U3 の入った版で止めて図ごとの悪化 0 を確かめてから外す。
- 実行は対象のファイルだけ。golden は U1・U3・U4 の PR で 1 回ずつ。

### 完了の基準

- ADR 0070 の完了の基準(fixture・報告の図)が、変わらず満たされる。
- 乱数の CRT で、**交差が main より増える図が 0**、並走の組(その図の倍率の線の間隔)が増える図が **幅 1800 で 4 枚以下・canvas で 2 枚以下**(U5 の #0・#4 を含む)。組の合計は 43 → 40・30 → 22 以下。
- 報告の図で AND の段差が 0。D3(ADR 0070)・D8 の弧と口の値が変わらない。
- 費用: 60 節 2.3s・120 節 4.5s を超えない。

## 未決

- **Q1(決める人)**: 高さの交換の上限(推奨 +25%。10% なら #106・#75 の利得を失う、50% でも利得は同じ)。
- **Q2(決める人)**: 折れ +1〜2% と引き換えに組 12〜33% を減らす D2 を採るか。
- **Q3(決める人)**: 層の並びを直接探す探索(焼きなまし)を別の ADR で検討するか。fixture の点 1(5 つの交差)は、層の間の交差の下限が 2 まで下がる(層の番号は図から取った測定。経路の交差は未確認)。入れるなら、D1 の高さの交換の上で、書く順を種にしない探索になる。
- **Q4(利用者へ)**: 報告の図の点 4(箱の左上の縦の線)は、fixture では AND の口の間隔(28px)と読んだ。どの線のことかを、利用者に確かめたい(未確認)。
- D12・D13 を外すかは、U4 で測ってから決める。
- minText が大きい図(24)で倍率を掛けた図が収まらない(倍率なしで描かれる)件は、この ADR の範囲外(ADR 0070 D7・PR #402)。
