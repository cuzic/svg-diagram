## 指摘

### M1（Major）: `'auto'` の段階 1・2・3 と `\n` の数え方をテストが区別できず、ADR の背景にある例（幅 940、8 字の `sub`）が守られていない

- **場所:** `lib/flow-chevron.ts:42`、`test/chevron-rows.test.ts:143-165`
- **問題:**
  - **テストの幅が ADR と違う。** テストは `roughWidth`（0.58em）で、幅 500 と 600 だけを使う。そこでは 1 段だと `sub` の余分な行が 2 行以上になるので、段階 2 も 1 段を断る。そのため、段階 1 の有無で結果が変わらない。
  - **実際のフォントでの試し:** `checkDiagram` で 7 つ、5 字のラベル、8 字の `sub` を描いた。
    - 今の実装は、幅 940 でも 1200 でも 2 段を選ぶ（ADR の n10 の表どおり）。
    - 段階 1 を消した変異では、どちらも **1 段**を選ぶ。12 字の `sub` を幅 1280 に並べた場合も、2 段から 1 段に変わる。
    - それでも全テストが通る。
  - **残りの段階も守られていない。** 段階 2 を消しても、段階 3 の同点の選び方を逆にしても落ちない。7 つでは `r` の候補が {1, 2} しかないため。
  - **改行のテストは空である**（`:161`）。step が 3 つなので `maxR = 1` になり、`'auto'` は必ず 1 段を返す。そのため、余分な行の式（`\n` で分けた数を引くこと、`max(0, …)`）をどう壊しても落ちない。
  - **ADR が求めたことが未実施:** n10 は「12 字の `sub` をスライドの幅に並べた場合は、実装の試しで確かめてテストに書く」と言っているが、まだしていない。
- **直し方:** `test/chevron-rows.test.ts` の U2 の節に、実際のフォント（`checkDiagram`。必要なら幅を固定）で次を足す。
  1. n10 の表の 3 行（8 字の `sub` で 940 / 1200 / スライド → 2、12 字で 940 → 2、16 字で 940 / スライド → 2）。12 字のスライドの値は、試しで決めて書く。
     - 少なくとも 8 字・940 の 1 件は、「段階 2 だけなら 1 段を選ぶ」例として置く。段階 1 を消す変異が落ちることを PR 本文に書く。
  2. 段階 2 と段階 3 を区別する例。`r` の候補が 3 つ以上ある `n`（たとえば 12 で `maxR = 4`）にする。
     - 段階 1 は満たせず、段階 2 で中間の `r` が選ばれる例。
     - 段階 3 で同点になり、小さい `r` を選ぶ例。
  3. 改行のテストは 6 つ以上の step で作り直す。`'手順\nA'` のラベルや、末尾が `\n` の `sub` で、1 段に決まること（`\n` を数えないと 2 段になること）を確かめる。

### m1（Minor）: `focus` と `connect()` のテストが、主張する振る舞いを見ていない

- **場所:** `test/chevron-rows.test.ts:95-96`、`:99-101`
- **問題:**
  - `focus` のテストは、`chevronBand(…, {focus: 5})` の `steps.length === 7` しか見ていない。2 段目の step が塗られ、ほかが弱められることは確かめていない。描いた図では正しく効いている。
  - `connect()` のテストは、`connects.length === 1` しか見ていない。テスト名の「アンカーは矢羽根の矩形」は確かめていない。
- **直し方:**
  - `focus`: 2 段目の step の polygon の tone（またはテキストの tone）が、他と違うことを assert する。
  - `connect()`: 線の始点が `s4` のアンカー（2 段目の矩形）の下辺にあることを assert する。

### m2（Minor）: `perRow: 1` の 2 点の線が ADR D4 の文と違う

- **場所:** `lib/flow-chevron.ts:100`、ADR 0082 D4
- **問題:**
  - 1 列のときは `xLast === xFirst` になる。このとき 4 点の中間の 2 点を落として、2 点の直線にしている。
  - 判断としては妥当。4 点のままだと、ゼロ長の線分（横の区間）ができる。PPTX でも、幅 9525 の 2 点の線で問題なく出る。
  - ただし D4 は「4 点の折れ線」としか書いていない。
- **直し方:** 受け入れる。U4 で ADR D4 に「1 列のとき（`perRow: 1` / `rows >= n`）は、始点と終点の 2 点の直線にする」と 1 行足す。
