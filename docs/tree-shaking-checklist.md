# Tree shaking 移行チェックリスト

対象は [ADR 0080](adr/0080-band-plugin.md) と、実装の `Band` と `LAYOUT_HANDLERS` が扱う全種類。公開ビルダーが同じ帯を作る場合は、その帯の行で派生形も検証する。

各帯の完了には、配布パッケージの入口から最小構成で描画できること、esbuild と Vite の出力に無関係な帯が入らないこと、既存の SVG と該当する他形式の出力・検査が保持されることが必要。試験的な縦積み SVG の検証は移行全体とは別に記録する。

## 共有基盤

- [x] SVG から HTML 出力を分離し、ブラウザの文字測定器を個別に公開する。
- [x] 既存の配置・測定処理を帯ハンドラーの解決元と分離する。
- [x] 子の探索・幅・スコープ・inventory の全帯テーブルを配置コアの外で結び付ける。
- [x] SVG の組み立て、共通の検査、パイプラインから全帯の描画・検査・規則テーブルへの直接依存を外す。
- [x] 選択 SVG の矢じりと等幅文字スタイルを帯の定義から要求する。行・グリッドとスイムレーンが出力する箱も従来版と照合。
- [x] 4px グリッドに丸めず配置する帯を個別の定義で指定する。木に埋め込んだ座標図の位置と接続端点を従来版と照合。
- [x] 箱とキャプションの配置を必要な帯の定義から読み込む。伸縮したグループの出典位置はグループの配置処理で保持する。
- [x] スライドの高さに収まらない因果図の再配置を因果図の定義から読み込む。ほかの帯のバンドルから除外する。
- [x] 題名・出典の自動キャプションをキャプションの入口から読み込む。従来の状態帯・題名・出典の生成は配置と測定で共有する。
- [x] 接続線の描画と配色付き矢じりの生成を接続線の入口から読み込む。行だけで使う矢じりと等幅文字スタイルは個別描画でも保持する。
- [x] 接続線の重なり、注釈と戻り線の領域外を検査する処理を接続線の定義から読み込む。戻り線の領域外に対するエラーを従来版と照合。
- [x] 接続ラベル用の行・列・スタックの間隔調整を接続線の定義から読み込む。接続線を使わないバンドルから除外する。
- [x] 行とシェブロンの戻り線の端点を帯の定義から取得し、接続線の定義で描画用の帯を生成する。グループ内の戻り線も従来版と照合する。
- [x] 配置結果の inventory を帯の定義から組み立てる。文字・枠・矢じり・接続線を従来版と照合し、既定の矩形も保持する。
- [x] 図の幅と余白の検査で、グリッドの子の外接矩形と、キャプション・凡例・状態帯の除外を個別定義から取得する。
- [x] 行・グリッド・グループの検査対象と、箱・キャプション・バナーの最小文字サイズを帯の定義から取得する。配色とスライド寸法の検査を従来版と照合。
- [x] SVG の箱・行・グリッド・キャプション・バナー・グループの描画を個別に読み込む。箱・行・グリッド・キャプション・グループのバンドルから従来の描画モジュールと不要な行・グリッドの描画を除外し、従来の SVG と照合。
- [x] 凡例・ピラミッド・人数・ドット・曲線・状態・raw・スイムレーンの SVG 描画を個別に読み込む。各構成で共通の描画ファイルと別の帯の描画がバンドルに入らないことを検証。
- [x] 表・シーケンスの SVG 描画と配置を分離し、ワイヤーフレーム・画面一覧の SVG 描画を独立させる。esbuild と Vite で、表とシーケンスの相互除外および画面構成からの両者の除外を確認。
- [x] 行・グリッド・領域・スペーサーのビルダーを個別に読み込む。esbuild と Vite で他のコンテナのビルダーが外れ、グリッドにはグループ生成が入らないことを確認。
- [x] 座標図・棒・四象限・フロー図形・時系列・木・状態・因果・クラウド・クラス・BPMN・数式の SVG 描画を個別に読み込む。専用構成のバンドルから従来の共通描画ファイルを除外。
- [x] 表・シーケンス・スイムレーンの入力ビルダーを個別に読み込む。各専用構成で他の入力ビルダーが外れることを esbuild と Vite で確認。
- [x] シェブロン・ファネル・サイクル・ベン・同心円・エンブレム・バリューチェーンの入力と配置を分離。専用構成で他の図形の入力・配置が入らないことを esbuild と Vite で確認。
- [x] 戻り線の入力検証・端点取得・接続線生成を分離。行とシェブロンの単独構成から接続線生成を、接続線だけを追加した構成から帯固有の戻り線入力検証と端点取得を除外。
- [ ] 子の探索、ID、reveal、配置のフィードバック、出力、検査と規則を帯の定義から呼ぶ。
- [ ] 既存と同じ配置処理を選択的な公開入口に接続する。
- [x] Node.js 向けの表・画像・数式の配布テストで、実際にコードを出力したモジュールを esbuild と Vite で照合する。数式から画像のファイル読み込みが外れることを確認。
- [ ] パッケージ入口ごとの実描画、依存の除外、サイズ予算、互換性を CI で全構成に検証する。

帯 47 種類と chart の内訳 20 種類の行は、配置ハンドラーと型に照らしてテストで照合する。各行の完了判定は冒頭の条件に従う。
