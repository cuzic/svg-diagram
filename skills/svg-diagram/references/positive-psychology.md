# ポジティブ心理学の図(PERMA・フロー・拡張–形成ほか)
（svg-diagram の入口は `../SKILL.md`）

ポジティブ心理学の説明図は、**専用の帯を持たず**、既存の部品で描く。用語は書籍・論文の訳語に合わせ、数字・場面は説明用の架空にする(割合や点数は「目安」と出典の欄に書く)。

| 描くもの | 使う部品 | 例 |
|---|---|---|
| PERMA(5 要素)の自己評価・目標との差 | `radar(axes, series, {max: 10, values: true})`。軸名は「P ポジティブ感情」のように頭文字を付ける。系列は「今」「目標」 | `examples/positive-perma.ts` |
| フロー(スキル × 挑戦度。斜めの「釣り合う帯」) | `quadrant.preset('positioning', {regions, items, arrows})`。`regions` は値の空間(0〜1)の多角形。右上がりの帯は `[[0, 0], [0.25, 0], [1, 0.75], [1, 1], [0.75, 1], [0, 0.25]]`、帯の外は不安(左上)・退屈(右下)の三角形。`arrows` で上達の道すじ | `examples/quadrant-flow.ts` |
| 拡張–形成理論(上昇スパイラル) | `cycle`(4 点)。節の文は 8〜10 字に収める(円の中で折れる) | `examples/positive-broaden-build.ts` |
| 幸福の決定要因(遺伝 50 / 環境 10 / 活動 40) | `stackedBars([{label, parts}], {percent: true})` の 1 本 | `examples/positive-determinants.ts` |

逆境からの回復曲線やヘドニア／ユーダイモニアの対比は、まだ試していない(`lines` / `versus` / `table` で描けるはずだが、例ができたらここに足す)。

## 落とし穴

- フロー図の `regions` は `crosshair: true` と、マスに見出しのない型(`positioning`)が条件。領域が文字を持つので、BCG などの型とは組めない。領域どうしの重ね合わせ・切り取りはなく、後ろが上に描かれる(無関心の角は最後に書く)。
- 領域の色だけに頼らない。`title` と `note` を必ず文字で書く。
- 割合・点数は研究の目安であって個人の内訳ではない。`sourceLine` に出典と「説明用に簡略化」を書く。
- 例の場面は説明用の架空。書籍の逸話・図は写さない。

## 帯にする条件

同じ配置の手書きが 3 つ以上の図で出たら、新しい ADR で帯を検討する。
