# 人間関係の図(Arbinger の「箱」、どろどろトライアングルほか)
（svg-diagram の入口は `../SKILL.md`）

『自分の小さな「箱」から脱出する方法』『平和の解剖』のような、人間関係を「相手をどう見るか」で説明する図は、**専用の帯を持たず**、既存の部品で描く（ADR 0032）。型の名前・用語は書籍の訳語で書く。例の場面は説明用の架空で、書籍の逸話は写さない。

| 描くもの | 使う部品 | 例 |
|---|---|---|
| 共謀（二人の見方と行動が互いを回す） | `cycle`（4 点: A の見方 → A の行動 → B の見方 → B の行動）。節の文は 12 字 × 2 行ほど。`centre` に「箱の中の二人」 | `examples/arbinger-collusion.ts` |
| 同じ行動、違う心の向き（氷山） | `banner`（行動）+ `banner`（水面）+ `row` + `group`。箱の外/中は **`tone: 'new'` / `'muted'`** と `legendLabels` | `examples/arbinger-iceberg.ts` |
| 自己正当化のイメージの型 | `table` | `examples/arbinger-images.ts` |
| 箱から出る流れと戻り | `chevron({loopBack})` | `examples/arbinger-way-out.ts` |
| 同じ 3 人が役割を回すドラマ(どろどろトライアングル=ドラマの三角形)と、構えが替わった後(しあわせトライアングル=TED) | 場面ごとの三角形を `row` で並べる。三角形は `group` の中に `row`(上 2 箱)+ `spacer(14)` + `row`(下 1 箱)。頂点(役割)は固定し、**箱の中の人だけを替える**(Ⓐ Ⓑ Ⓒ の記号で追う)。変わらない構えは外側の `group` の見出しに書き、下に「人 × 場面」の `table`。場面どうしは `connect` | `examples/drama-triangle.ts` |

## 落とし穴(試作で踏んだもの)

- **二人を左右の列に縦に積み、列をまたぐ矢印を引かない。** 同じ順で積むと矢印が箱を貫いて、ビルドが止まる(`path overlaps`)。循環は `cycle`（`causalLoop({layout: 'ring'})` でも描けるが、+/− と `R1` の印が付く）。
- **箱の中/外に `danger` / `removed` を使わない。** 凡例が「異常・注意」「対象外」と出て、意味が逆に読める。`legendLabels: {'tone:muted': '箱の中(…)'}` で文言を直し、色だけに頼らず、ラベル（「箱の中/外」）を必ず文字で書く。
- `plain` は凡例に出ない（`legendLabels` のキーにも無い）。凡例に出したい意味には `new` / `muted` などを使う。白黒で近いトーンの組は `gray-tone-collision` が出る。トーンを減らすか、`accept` に理由を書く。
- 箱の外の人に自己正当化を書けるかは、DSL が決めない（心の向きは特定の相手・時点に対するもので、書籍の主張を型にしない）。

## どろどろトライアングルを描くとき(ADR 0034)

- 見せたいのは「**役割は入れ替わるが、構え(犠牲者のマインドセット)は変わらない**」こと。1 つの三角形に人ごとの線を引くと、番号のチップが重なって読めない(ビルドの検査も通らない)。場面ごとの三角形を並べ、人だけを替える。
- 役割は色だけでなくラベルの文字と線(迫害者=`danger` の破線、挑戦者=`dashed: true`)でも区別する。`gray-tone-collision` は理由を書いて `accept` にする。
- `row` は、グループ同士に `arrows: 'between'` が使えない。`group` に `id` を付けて `connect('a1:right', 'a2:left')` で結ぶ。
- 箱の欄は `title` / `body`。三角形の上段と下段の間は `spacer(14)` 以上(狭いと斜めの矢印のラベルが箱に重なる)。発言は 1 行(20 字ほど)に収める。長いと折れて箱の高さがずれる。
- 場面ごとの発言は、頂点の箱ではなく三角形の下の `box({body})` に置く(頂点には同じ役割の人が何度も出るため、`callout` では置き場がない)。
- **用語は松村亜里『うまくいかない人間関係逆転の法則』(すばる舎)に合わせる**: 犠牲者・迫害者・救済者の悪循環を「どろどろトライアングル」(ドラマの三角形、DDT)、犠牲者→クリエイター、迫害者→挑戦者、救済者→コーチと変わる図を「しあわせトライアングル」(TED)と書く。「クリエイター」「コーチ」は本の目次、「挑戦者」は用語の指定による(本文は未確認)。「構え」(土台)は本の用語ではなく、この例の言葉。
- しあわせトライアングルの三角形の向きは原典で未確認。図には「作図上の配置」と書く。

## 帯にする条件

同じ配置の手書きが 3 つ以上の図で出たら、新しい ADR で帯を検討する（ADR 0032「帯に戻す条件」）。
